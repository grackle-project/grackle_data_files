UV background tables (2026-09-16)
========================================

This file records UV background (UVB) tables and their /UVBRates/Info identifiers.
File versions are stored in a root-level string attribute named version.
Files without this attribute are version 1.

CloudyData_UVB=HM2012.h5 and CloudyData_UVB=HM2012_shielded.h5 have
version = "2" and include the five metal photo-rates listed below.
These two files also carry a HydrogenFractionByMass attribute on the
/CoolingRates/Primordial group. Grackle does not yet read either attribute;
tabulated mode (primordial_chemistry = 0) uses the historical fixed value.

Tables
------
CloudyData_UVB=HM2012.h5
  version   "2"
  Info      Haardt & Madau (2012, ApJ, 746, 125) [Galaxies & Quasars];
            Grackle metal UVB extension (generated 2026-09-04):
            kphCI, kphOI, kdissCO, kdissOH, kdissH2O; Leiden cross sections
            (Heays, Bosman & van Dishoeck 2017); kdissH2O=total
  z grid    59 points, 0 <= z <= 15.13
  datasets  /UVBRates/Chemistry:    k24 k25 k26 k27 k28 k29 k30 k31
            /UVBRates/Photoheating: piHI piHeI piHeII
            /UVBRates/Chemistry: kphCI kphOI kdissCO kdissOH kdissH2O
            (kdissH2O is computed from the total H2O cross section; grackle applies it
            to the OH + H channel only)
